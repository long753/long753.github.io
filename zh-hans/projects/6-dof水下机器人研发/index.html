6-DOF水下机器人研发

6-DOF全自由度水下机器人结构设计、控制方案与扩展模块设计
2026年2月8日 Robot Machine Control

1. 项目概述

本文设计了一款6-DOF全驱动水下机器人（AUV），旨在完成水下抓取任务与高性能运动控制。与传统欠驱动或冗余驱动的AUV相比，6-DOF全驱动方案能够在紧凑设计的基础上实现更高水平的运动控制能力。为同时满足高精度水下抓取与高性能运动控制，本文设计了AUV的两种运动模式：抓取模式与巡航模式。抓取模式使用传统控制方案以提升其精度，巡航模式使用DRL驱动以实现其平滑运动需求。此外，该AUV还设计了4个扩展模块接口，用于连接不同的扩展模块以满足多样的水下作业任务。

1.1 设计目标

  • 高性能的机械结构设计
  • 传统控制方案设计
  • DRL控制方案设计
  • 自主路径导航
  • 目标识别与抓取
  • 扩展模块开发

1.2 技术支持

  • mjlab & mojoco
  • ROS2
  • SSH & Git
  • python & C++

2. 结构设计

2.1 推进器分布方案

推进器分布分为三类：欠驱动、全驱动和冗余驱动。

类型 特点 适用场景
欠驱动 推进器数量少于自由度数 简单观测任务
全驱动 推进器数量等于自由度数 精细作业任务
冗余驱动 推进器数量多于自由度数 高冗余任务

考虑到机器人需要在紧凑设计的基础上实现高水平的抓取任务，本文选用6-DOF全驱动方案。

常规全驱动方案使用6个独立固定推进器，该方案控制策略较为成熟，但不利于紧凑设计。因此，本文设计了了一种4推进器+2舵机的非对称矢量推进方案：

  • 4个主推进器控制推力大小
  • 2个舵机控制4个推进器的推力方向
  • 4个推进器成十字分布，上下推进器旋转方向相反，左右推进器旋转方向相同

3. 控制方案

3.1 基于PID的控制方案

对于抓取模式，为保证运动的精确性，采用PID控制器进行底层运动控制：

CPP 
class PIDController {
public:
    double kp, ki, kd;
    double setpoint, current_value;
    double integral = 0;
    double last_error = 0;
    
    double compute(double feedback) {
        double error = setpoint - feedback;
        integral += error;
        double derivative = error - last_error;
        last_error = error;
        return kp * error + ki * integral + kd * derivative;
    }
};
class PIDController { public: double kp, ki, kd; double setpoint, current_value; double integral = 0; double last_error = 0; double compute(double feedback) { double error = setpoint - feedback; integral += error; double derivative = error - last_error; last_error = error; return kp * error + ki * integral + kd * derivative; } };

3.2 基于DRL的控制策略

3.3.1 场景配置（Scene）

  • 环境数量: 支持大规模并行训练
  • 地形类型: 平地（plane）水下环境
  • 机器人: AUV 无人水下航行器

3.3.2 动作空间（Actions）

AUV 具有两类执行器：

执行器类型 关节名称 作用 动作尺度
舵机 joint_servo_up, joint_servo_left 控制方向舵角度 ±1.5 rad
推进器 joint_prop_up, joint_prop_down, joint_prop_left, joint_prop_right 推力大小 (-30N,43N)

3.3.3 指令空间（Commands）

速度指令生成器使用 UniformVelocityCommandCfg，生成的指令包括：

  • 线速度指令:
    • X轴（前后）: -0.5 ~ 2.0 m/s
  • 角速度指令:
    • X轴（roll）: -1.0 ~ 1.0 rad/s
    • Y轴（pitch）: -1.0 ~ 1.0 rad/s
    • Z轴（yaw）: -1.0 ~ 1.0 rad/s

3.3.4 观测空间（Observations）

Agent 接收的观测信息包括：

观测项 描述 维度
command 目标速度指令 4
base_lin_vel 机身线速度 3
base_ang_vel 机身角速度 3
projected_gravity 重力投影向量 3
joint_pos 舵机角度 2
joint_vel 关节速度 6
last_action 上一帧动作 8

3.3.5 奖励函数（Rewards）

奖励设计分为核心目标奖励和惩罚项：

核心奖励:

  • track_linear_velocity: 跟踪目标线速度
  • track_angular_velocity: 跟踪目标角速度
  • alive:生存奖励

惩罚项:

  • action_rate_l2: 惩罚动作变化率，防止电机抖动（权重 -0.01）
  • action_l2: 惩罚动作幅值，鼓励节能（权重 -0.005）
  • joint_acc_l2：惩罚关节加速度

3.3.6 事件系统（Events）

  • 关节重置: 训练开始时重置机器人关节状态
  • 水动力学: 添加水中的阻力与浮力

3.3.7 终止条件（Terminations）

  • time_out: 超过一定时间
  • excessive_lin_vel: AUV线速度过快终止
  • excessive_lin_vel：AUV角速度过快终止

3.3.8 课程学习（Curriculum）

为提升训练的收敛效果，本文设置了课程学习，并将AUV的训练划分为3个阶段：

  • 第一阶段，只训练速度或者角速度的其中一个维度
  • 第二阶段，训练速度和单一方向的角速度
  • 第三阶段，训练速度和任意s方向的角速度

5. 项目复现

5.1 环境要求

  • Python 3.11
  • CUDA 11.8+（GPU 训练）
  • Mujoco 物理引擎
  • mjlab最新版本

5.2 训练

BASH 
uv run scripts/train.py Mjlab-Velocity-Flat-CQU-AUV --env.scene.num-envs=并行数量 --agent.max-iterations=回合数量
uv run scripts/train.py Mjlab-Velocity-Flat-CQU-AUV --env.scene.num-envs=并行数量 --agent.max-iterations=回合数量

5.3 回放

BASH 
uv run scripts/play.py Mjlab-Velocity-Flat-CQU-AUV \
    --checkpoint-file logs/rsl_rl/auv_velocity/时间戳/model_第几个回合.pt \
    --num-envs 1 \
    --viewer viser \
    --no-terminations True
